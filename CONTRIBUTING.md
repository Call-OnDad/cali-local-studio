# Contributing

Keep the core workflow CPU-capable and self-hosted. Please do not add a silent hosted-generation fallback. Describe the user-visible problem, the change and checks in each contribution.

Run the control tests and a real smoke render for engine/queue/export changes. Check a fresh browser at desktop/mobile sizes and verify actual decoded frames for layout work. Never include user projects, recordings, model weights, keys, local deployment notes or private addresses in a pull request.

New engines/models need explicit source/terms, local setup instructions, resource requirements and an actual completed workload. Do not bypass upstream model licence gates or label an installed package as a proven integration.
