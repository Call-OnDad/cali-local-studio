# Cali Local Studio

CPU-only, self-hosted 2D video creation. Keep all inference local; never introduce a paid provider fallback. Preserve the distinction between automatic timing checks and perceptual performance quality.

Do not commit data, model weights, binaries, recordings, environment files, credentials or deployment-specific addresses. Do not modify upstream model licence gates. Keep third-party notices and actual capability limits current.

Run `python -m unittest -v test_controls` for API/control changes. Use `scripts/smoke_test.py` with installed models/tools for a real end-to-end render. Validate responsive UI and actual decoded video frames for layout changes. Commit specific files only; no force pushes.
